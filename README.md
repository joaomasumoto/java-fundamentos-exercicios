# Java Fundamentos - Exercicios

Repositorio de estudos com exercicios pequenos em Java, organizados por tema. O objetivo e registrar a evolucao nos fundamentos da linguagem sem misturar esses codigos com projetos maiores de portfolio.

Os exercicios foram mantidos como solucoes independentes. Alguns usam pacote default e nomes simples como `Program.java`, entao a estrutura preserva cada atividade em sua propria pasta.

## Organizacao

- `fundamentos/` - entrada e saida, variaveis, condicionais, lacos, strings, arrays e matrizes.
- `poo/` - classes, objetos, enumeracoes, organizacao em pacotes e pequenas regras de negocio.
- `datas/` - exercicios com datas, horarios e manipulacao de tempo.
- `excecoes/` - tratamento de erros, excecoes personalizadas e validacoes.
- `algoritmos/` - solucoes curtas de problemas de logica e plataformas de treino.
- `aquecimento/` - lista de praticas curtas para reforcar sintaxe e logica.
- `devdojo/` - exercicio de relacionamento entre classes feito durante estudos do curso DevDojo.

## Como executar

Abra a pasta de um exercicio na sua IDE Java ou compile pelo terminal. Exemplo:

```bash
cd fundamentos/tabuada/src
javac Program.java
java Program
```

Para exercicios com pacotes, compile a partir da raiz do `src` correspondente, respeitando a estrutura de diretorios.

Os exercicios do LeetCode possuem testes simples com metodo `main`. A ordem sugerida, os temas e os comandos de teste estao em [`algoritmos/leetcode/README.md`](algoritmos/leetcode/README.md).

## Observacoes

- Este repositorio e propositalmente simples: ele documenta exercicios de estudo, nao uma aplicacao final.
- Projetos maiores, como sistemas web e APIs, devem ficar em repositorios proprios.
- Materiais de curso em PDF nao foram incluidos para manter o repositorio autoral e organizado.
